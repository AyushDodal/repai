# FitTrack
## A FITNESS TRACKING AI AGENT.

I designed a Remote MCP Server and used it to integrate my fitness web-app with ChatGPT.

Now I can "speak" (voice or text) to ChatGPT, giving it information about my workouts, and it updates the web-app for me, thereby making the workout logging process simpler, faster & more efficient.
